# معرض الأعمال الشخصي | مطور ومبرمج مواقع وتطبيقات ويب سحابية

معرض أعمال (Portfolio) فائق الجمال والأداء، مبني ومصمم خصيصاً لمطوري ومبرمجي الويب، يدعم **اللغة العربية بالكامل (RTL)** مع نظام **دارك مود افتراضي (Dark Mode)** وإمكانية التبديل إلى الوضع النهاري بسلاسة وحفظ التفضيل.

---

## 🌟 هيكل الصفحة
الصفحة تركز بالكامل وبشكل مباشر على:
1. **الواجهة الرئيسية (Hero Section):** تقديم سريع ومختصر مع بطاقة المطور وعداد الإحصائيات الحية.
2. **معرض الأعمال (Projects Showcase):** استعراض حي وتفاعلي للمشاريع الثلاثة مع فلترة حسب التصنيف وزر للمعاينة وزر للتفاصيل المنبثقة (Modal).
3. **قسم التواصل المباشر (Contact Section):** في أسفل الصفحة للتواصل السريع عبر واتساب ونموذج المراسلة والبريد الإلكتروني.
1. **استوديو الحرم ([studio.basmatandalusia.cc](https://studio.basmatandalusia.cc/))**:
   - **التصنيف:** منصات سحابية متكاملة (SaaS).
   - **الوصف:** منصة عربية سحابية موجهة لاستوديوهات التسجيل الصوتي والمؤسسات القرآنية لإدارة القرّاء، تسجيلات الكتب والمصاحف، ومراحل التدقيق والمونتاج الصوتي وإصدار مستحقات العمل والناشرين.
   - **التقنيات:** Next.js, React, Tailwind CSS, Audio Flow, SaaS Architecture, RTL.

2. **بصمة أندلسية ([www.basmatandalusia.cc](https://www.basmatandalusia.cc/))**:
   - **التصنيف:** مواقع وشركات رقمية.
   - **الوصف:** البوابة الرقمية الرسمية لشركة ووكالة بصمة أندلسية للحلول البرمجية، متخصصة في تطوير المواقع وتطبيقات الويب المخصصة وتصميم واجهات UI/UX حديثة.
   - **التقنيات:** Modern JavaScript, Responsive CSS3, SEO Architecture, Core Web Vitals, UX/UI Systems.

3. **محول صيغ الصور WebP Converter ([converter.hichemmadina.workers.dev](https://converter.hichemmadina.workers.dev/))**:
   - **التصنيف:** أدوات وسيرفرلس (Edge & Tools).
   - **الوصف:** أداة ويب سحابية فائقة السرعة لتحويل وضغط الصور بصيغة WebP معتمدة على خوادم Cloudflare Workers وحوسبة الحافة (Edge Computing) لمعالجة فورية وتوفير يصل إلى 85% من حجم الصور دون فقدان الجودة.
   - **التقنيات:** Cloudflare Workers, Serverless, Edge Computing, Canvas API, WebP.

## 🚀 المميزات والخصائص التقنية
- **تصميم دارك مود متقدم (Dark Mode First):** ألوان مريحة للعين مع تدرجات ضوئية انسيابية (Ambient Glow Orbs) وتأثيرات زجاجية (Glassmorphism).
- **تبديل فوري للمظهر:** زر تفاعلي للتحويل بين الوضعين الليلي والنهاري مع حفظ اختيار الزائر في `localStorage`.
- **دعم كامل للغة العربية (RTL First):** خطوط عربية حديثة واحترافية من Google Fonts (`Cairo` للنصوص العربية و `Plus Jakarta Sans` للأرقام والأكواد).
- **فلترة المشاريع التفاعلية:** تبويبات لتصفية الأعمال (الكل، منصات سحابية SaaS، مواقع وشركات، أدوات وسيرفرلس).
- **نافذة تفاصيل المشاريع (Modal):** نافذة منبثقة أنيقة ومتحركة بأسلوب Apple Design تتيح استعراض تفاصيل كل مشروع ومميزاته وروابطه المباشرة.
- **عداد إحصائيات حي (Live Counter):** أرقام متحركة وسلسة عند التمرير تعرض سنوات الخبرة وعدد المشاريع ومعدل الرضا.
- **نموذج تواصل تفاعلي:** يتيح إرسال رسائل استفسار وتوجيهها مباشرة إلى محادثة واتساب منسقة أو البريد الإلكتروني.
- **نسخ فوري للبيانات:** إمكانية نسخ البريد الإلكتروني بنقرة واحدة مع ظهور إشعار توست (Toast Notification).
- **متجاوب 100% (Fully Responsive):** تجربة استخدام مثالية على الهواتف الذكية، الأجهزة اللوحية، والشاشات العريضة.

## 💻 طريقة التشغيل
يمكنك فتح ملف `index.html` مباشرة بالنقر المزدوج في أي متصفح، أو تشغيل سيرفر محلي خفيف:

```bash
# باستخدام بايثون
python -m http.server 3000

# أو فتح الصفحة مباشرة
start index.html
```
ثم فتح المتصفح على: `http://localhost:3000`
